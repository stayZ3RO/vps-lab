## Redaction Standard

Before screenshots are committed, sensitive values are redacted or excluded.

Redacted items include:

- Public IPv4 addresses
- IPv6 addresses
- Tailscale IPs
- SSH host fingerprints
- Provider account details
- Customer numbers
- Email addresses
- Authentication URLs
- API keys
- SSH keys
- Billing details
